# ai-joke-03: Make the AI judge laugh

An entry for the make.fun bounty "Make the AI judge laugh".

## The Joke

## How to Run
Set the `MAKEFUN_OUTPUT_DIR` environment variable and run `main.py`:

```bash
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
